# PR2 — Custom MCP Server & Adapter Integration: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps
> use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A custom MCP server exposing 3 domain tools + 1 resource (template) over stdio,
consumed by the agent via `langchain-mcp-adapters`, with committed capability + tool-call
evidence. Closes AC-09; partially closes AC-10 (full agent-in-the-loop transcript is PR7).

**Architecture:** `mcp_server/data_access.py` holds all domain lookup logic as pure
functions over the PR1 synthetic corpora (unit-testable with no server). `mcp_server/server.py`
is a thin FastMCP layer — `@mcp.tool()` / `@mcp.resource()` wrappers that delegate to
`data_access`. `mcp_client.py` builds a `MultiServerMCPClient` pointed at
`python -m pa_copilot.mcp_server` (stdio) and exposes helpers to load the LangChain tools
and read the criteria resource. Evidence is generated by tests that spin the real server
subprocess.

**Tech Stack:** `mcp>=1.9` (`mcp.server.fastmcp.FastMCP`), `langchain-mcp-adapters`,
`langchain-core`, Pydantic v2, `pytest` + `pytest-asyncio`.

**Spec:** `docs/design.md` §4 (MCP server & client), §7 (RAG boundary — for the
integration-decision contrast); `specs/acceptance-criteria.md` AC-09, AC-10; `specs/nfr.md`
NFR-04, NFR-06.

## Global Constraints

- Python `>=3.11`. Package `pa_copilot` under `src/`. MCP server runnable as
  `python -m pa_copilot.mcp_server` (via `mcp_server/__main__.py`).
- Google Gemini is the only LLM provider. No API keys in the repo; live-LLM tests are
  `@pytest.mark.slow` and skip when `GEMINI_API_KEY` is unset.
- No Docker, no external DB service. The MCP server reads the synthetic corpora **directly**
  from `data/synthetic/{benefits,providers,criteria}.json` (path from
  `Settings.synthetic_dir`) — no copy under `src/`.
- All data synthetic. Provider names + member ids must never reach `traces/*.json` in
  plaintext — build every tracer with `default_redact_values()` (PR1) already unioned in;
  do not pass raw names into trace payloads.
- Test output must be pristine (the warning trap turns any new warning into an error).
- Every AC artifact + test carries its `AC-NN` identifier. Committed evidence lands in
  `traces/`.
- Work on branch `feat/mcp-server`; final step is handled by the controller
  (`git merge --no-ff` after a whole-branch review — do NOT merge inside a task).
- TDD: failing test first, minimal implementation, passing test, commit.

## Task 2: `mcp_server/data_access.py` — pure domain lookups

**Files:**
- Create: `src/pa_copilot/mcp_server/__init__.py` (empty), `src/pa_copilot/mcp_server/data_access.py`
- Test: `tests/test_mcp_data_access.py`

**Interfaces:**
- Consumes: `pa_copilot.config.load_settings`.
- Produces (all return plain JSON-serializable dicts; **never raise on a miss**):
  - `load_corpora(synthetic_dir: str | Path | None = None) -> dict` — reads the 3 JSON
    files once; returns `{"benefits":..., "providers":..., "criteria":...}`. Defaults to
    `load_settings(env_file=None).synthetic_dir`.
  - `benefit_lookup(member_id: str, service_code: str, *, corpora: dict | None = None) -> dict`
    → `{"found": bool, "member_id", "service_code", "plan_id": str | None,
    "covered": bool, "requires_pa": bool, "network_status": str | None,
    "note": str}`. Miss (unknown member or service not in `covered_services`):
    `found=False, covered=False, requires_pa=False, note="member not found" |
    "service not covered under plan"`.
  - `provider_lookup(npi: str, *, corpora=None) -> dict`
    → `{"found": bool, "npi", "name": str | None, "specialty": str | None,
    "network_status": str | None, "note": str}`.
  - `criteria_check(service_code: str, diagnosis_codes: list[str], *, corpora=None) -> dict`
    → `{"found": bool, "policy_id": str | None, "title": str | None,
    "required_conditions": [{id,text}], "exclusions": [str],
    "evidence_requirements": [str], "excluded_diagnoses": [str],
    "status": Literal["not_found","excluded","indeterminate"], "note": str}`.
    Logic: no policy whose `service_code` matches → `not_found`. Else if any code in
    `diagnosis_codes` is in the policy's `excluded_diagnoses` → `status="excluded"`,
    `note="diagnosis <code> is a documented exclusion for this policy"`. Else
    `status="indeterminate"`, `note="policy criteria require clinical assessment;
    mechanical check cannot verify conditions"`.
  - `get_policy(policy_id: str, *, corpora=None) -> dict` → the full policy dict or
    `{"found": False, "policy_id": policy_id}`.
  - `list_policies(*, corpora=None) -> dict` → `{"policies": [{"policy_id", "service_code",
    "title"}]}`.

      → `data_access.get_policy(policy_id)`

import json
import sys
from pathlib import Path

import pytest
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

from pa_copilot.config import load_settings

pytestmark = pytest.mark.asyncio

SERVER = StdioServerParameters(command=sys.executable, args=["-m", "pa_copilot.mcp_server"])


async def _session(cm_stack):
    read, write = await cm_stack.enter_async_context(stdio_client(SERVER))
    session = await cm_stack.enter_async_context(ClientSession(read, write))
    await session.initialize()
    return session


async def test_ac09_server_exposes_three_tools_and_the_resource():
    import contextlib

    async with contextlib.AsyncExitStack() as stack:
        session = await _session(stack)

        tools = (await session.list_tools()).tools
        names = {t.name for t in tools}
        assert {"benefit_lookup", "provider_lookup", "criteria_check"} <= names

        templates = (await session.list_resource_templates()).resourceTemplates
        assert any("pa://criteria/{policy_id}" in t.uriTemplate for t in templates)
        resources = (await session.list_resources()).resources
        assert any(str(r.uri) == "pa://criteria/index" for r in resources)

        bl = await session.call_tool("benefit_lookup",
                                     {"member_id": "M100001", "service_code": "72148"})
        payload = json.loads(bl.content[0].text)
        assert payload["requires_pa"] is True

        cc = await session.call_tool("criteria_check",
                                     {"service_code": "72148", "diagnosis_codes": ["M54.16"]})
        assert json.loads(cc.content[0].text)["status"] == "indeterminate"

        res = await session.read_resource("pa://criteria/PA-PSG")
        assert json.loads(res.contents[0].text)["service_code"] == "95810"

        # write the capability evidence
        caps = {
            "server": "pa-copilot",
            "tools": sorted(names & {"benefit_lookup", "provider_lookup", "criteria_check"}),
            "resource_templates": [t.uriTemplate for t in templates],
            "static_resources": [str(r.uri) for r in resources],
        }
        out = Path(load_settings(env_file=None).traces_dir) / "mcp_capabilities.json"
        out.write_text(json.dumps(caps, indent=2) + "\n", encoding="utf-8", newline="\n")

```python
import os


@pytest.mark.slow
@pytest.mark.skipif(not os.environ.get("GEMINI_API_KEY"), reason="needs GEMINI_API_KEY")
async def test_ac10_gemini_agent_invokes_mcp_tool_transcript(tmp_path):
    from langchain.chat_models import init_chat_model

    s = load_settings(env_file=None)
    tools = await load_pa_tools()
    model = init_chat_model(f"google_genai:{s.model_agent}", temperature=0).bind_tools(tools)

    msgs = [{"role": "user", "content": (
        "A provider requests prior auth for service 72148, diagnosis M54.16, member "
        "M100001. Use the available tools to check the benefit and the coverage criteria, "
        "then summarize what you found."
    )}]
    transcript = ["# MCP tool-call transcript (Gemini agent -> pa MCP server)\n"]
    by_name = {t.name: t for t in tools}

    for _ in range(4):
        ai = await model.ainvoke(msgs)
        msgs.append(ai)
        if not ai.tool_calls:
            transcript.append(f"\n## final answer\n\n{ai.content}\n")
            break
        for tc in ai.tool_calls:
            transcript.append(f"\n## tool call: `{tc['name']}`\n\n```json\n"
                              f"{json.dumps(tc['args'], indent=2)}\n```\n")
            obs = await by_name[tc["name"]].ainvoke(tc["args"])
            transcript.append(f"\n## tool result\n\n```json\n{obs}\n```\n")
            msgs.append({"role": "tool", "content": str(obs), "tool_call_id": tc["id"]})

    out = Path(load_settings(env_file=None).traces_dir) / "mcp_toolcall_transcript.md"
    out.write_text("".join(transcript), encoding="utf-8", newline="\n")

    body = out.read_text(encoding="utf-8")
    assert "tool call: `criteria_check`" in body or "tool call: `benefit_lookup`" in body
```

  - **Options considered** — (a) custom **MCP server** over stdio; (b) plain in-process

    workers; (e) **A2A** (agent-to-agent) between the copilot and a separate "payer
    systems" agent.
  - **Decision: MCP server.** Rationale: models the real inter-system boundary a payer
    exposes (benefit + criteria systems are separate systems of record); protocol-mediated
    so the backing store is swappable without touching the agent; gives tools *and* a
    readable resource (`pa://criteria/{policy_id}`) in one server; and the brief mandates a
    custom MCP server consumed via `langchain-mcp-adapters`.
  - **Why not the others** — plain `@tool`: no inter-system boundary, no resource concept,
    doesn't exercise the interoperability requirement. REST API: needs a running web
    service (the No-Docker / no-service rule) and re-implements what MCP standardizes.
    Direct DB/file access: couples every worker to the storage layout; no protocol contract.
    A2A: the workers already share one LangGraph state; there is no negotiation or
    autonomy boundary between them and "payer systems" that A2A would earn — it would be
    ceremony over a plain data lookup.
  - **Boundary with RAG** — MCP = structured, deterministic system-of-record lookups
    (`criteria_check` returns the policy checklist + a mechanical `status`); RAG =
    unstructured narrative interpretation the `medical_necessity` agent reaches for only
    when `criteria_check` returns `indeterminate`.
