## Design decisions & rulings (recorded here; do not re-litigate mid-task)

- **`pac resume` calls `graph.ainvoke(Command(resume=<value>), config={"configurable":
  {"thread_id": case_id}})` on a freshly-built graph in a new process — nothing else.**
  `human_review.py`'s node already resets `supervisor_hops`/`replan_count` to 0 on any
  resume (PR6, tested in `tests/test_agent_human_review.py` and
  `tests/test_ac05_checkpointer.py::test_resume_completes_without_a_manual_hop_reset`).
  Do **not** add a manual `update={"supervisor_hops": 0}` in the CLI the way
  `scripts/run_pause_resume_test.py`'s comment-block explains was needed *before* PR6
  fixed the source — that workaround is now redundant and must not be reintroduced.
- **`thread_id` == `case_id`.** Verified against `tests/test_ac05_checkpointer.py` and
  `scripts/run_pause_resume_test.py` (`THREAD = {"configurable": {"thread_id": CASE_ID}}`)
  — this is the established convention, not a new choice.
- **`pac persistence-test` and the pause/resume evidence path wrap the EXISTING scripts'
  logic, not reimplement it.** `scripts/run_persistence_test.py` and
  `scripts/run_pause_resume_test.py` already contain the real two-process logic (via
  `subprocess.run` re-invoking themselves) and are the actual producers of
  `traces/memory_persistence.log` / `traces/pause_resume_transcript.md`. `pac
  persistence-test` shells out to `scripts/run_persistence_test.py` (`subprocess.run([sys.executable,
  <path>], check=True)`) rather than duplicating its process-spawning logic inside `cli.py`.
  There is no `pac pause-resume-test` command (design.md's CLI table has no such row) —
  that stays a `make pause-resume-test` / direct-script artifact producer only.
- **`pac ingest` = RAG index build + synthetic-data presence check**, not a second data
  generator. `data/synthetic/` is generated by PR1's generators and already committed;
  "seed synthetic MCP data" means confirming those files exist (the MCP server reads them
  directly, per design.md §4.1 — there is nothing to "seed" at runtime beyond what's
  already on disk). `pac ingest` therefore: (a) calls `rag.corpus.write_chunks_jsonl` +
  `rag.index.build_index()` (mirrors `scripts/ingest_rag.py`'s `main()` exactly — this task
  imports and calls that script's logic via a shared helper rather than re-deriving it —
  see Task 1), (b) asserts `data/synthetic/*.json` exist and raises a clear error naming
  `scripts/make_samples.py`/the generator scripts if not (defensive, not a new generator).
- **`single_agent.py` binds ALL tools the four workers collectively use**, unscoped by
  worker boundary, since a single agent has no worker boundary. Memory tools bind to the
  same `("pa", "member", "{member_id}")`-style namespace `intake`/`decision_draft` already
  use (`memory/tools.py::build_memory_tools`) — reusing the existing helper, not writing a
  new one. Ruling risk if wrong: `pac compare`'s observations doc might read as unfair to
  the single-agent baseline if the multi-agent system's context-engineering advantages
  (quarantine, `select_for`) have no analogue here — that asymmetry is exactly the
  observation `docs/single-vs-multi-agent.md` is supposed to report, not paper over.
- **The Streamlit app is not unit-tested via `streamlit.testing.v1.AppTest`.** Checked:
  `streamlit>=1.36` is declared but the installed version was not re-verified against
  `AppTest`'s minimum (1.28+, likely fine, but `AppTest` exercises the full Streamlit
  script-run machinery and is heavier than this PR's budget justifies for a UI that is
  explicitly a "Good-to-Have... covers the UI Good-to-Have" per design.md, not an AC/NFR
  gate). Instead: extract every piece of rendering logic that has real branching (routing
  trail row-building, memory-panel row-building, artifact-filling-in state) into plain
  functions at module level, unit-test those directly, and leave the `st.*` calls in a thin
  `main()` that is exercised only by `pac demo` launching `streamlit run` as a subprocess
  (smoke-tested by successful process start, not full render assertions).
- **The full genuine MCP transcript stays a scripted-model artifact**, per Architecture
  point 4 above — this is not a scope reduction, it is the same rule every other
  LLM-needing artifact in this repo already follows (Global Constraints, carried from every
  prior PR). Do not attempt to acquire a `GEMINI_API_KEY` or gate this task on one.

from __future__ import annotations

import asyncio
import dataclasses
import subprocess
import sys
from pathlib import Path

import typer

from pa_copilot.config import get_settings
from pa_copilot.memory.store import open_memory_store
from pa_copilot.rag import corpus
from pa_copilot.rag.index import build_index

app = typer.Typer(help="Prior-authorization copilot CLI.")
memory_app = typer.Typer(help="Inspect long-term memory.")
app.add_typer(memory_app, name="memory")

_REPO_ROOT = Path(__file__).resolve().parents[2]


@app.command()
def ingest() -> None:
    """Build the clinical-guidance RAG index and verify synthetic data is present."""
    settings = get_settings()
    synthetic_dir = Path(settings.synthetic_dir)
    required = ["benefits.json", "criteria.json", "providers.json"]
    missing = [f for f in required if not (synthetic_dir / f).exists()]
    if missing:
        typer.echo(
            f"Missing synthetic data files under {synthetic_dir}: {missing}. "
            "Run the PR1 generators (see data/synthetic/ scripts) first.",
            err=True,
        )
        raise typer.Exit(code=1)

    chunks_path = Path(settings.data_dir) / "synthetic" / "clinical_guidance_chunks.jsonl"
    corpus.write_chunks_jsonl(chunks_path, corpus.load_guidance(Path(settings.synthetic_dir) / "clinical_guidance"))
    typer.echo(f"wrote {chunks_path}")

    summary = build_index(settings)
    typer.echo(f"RAG index built: {dataclasses.asdict(summary)}")


@memory_app.command("list")
def memory_list(namespace: str) -> None:
    """List keys under a memory namespace, e.g. 'pa,member,M100001'."""
    ns = tuple(namespace.split(","))
    settings = get_settings()
    store = open_memory_store(settings.memory_db, settings=settings, semantic=False)
    try:
        items = asyncio.run(store.asearch(ns))
        for item in items:
            typer.echo(f"{item.key}: {item.value}")
    finally:
        store.conn.close()


@memory_app.command("search")
def memory_search(namespace: str, query: str, limit: int = 5) -> None:
    """Semantic/keyword search a memory namespace."""
    ns = tuple(namespace.split(","))
    settings = get_settings()
    store = open_memory_store(settings.memory_db, settings=settings, semantic=True)
    try:
        items = asyncio.run(store.asearch(ns, query=query, limit=limit))
        for item in items:
            typer.echo(f"{item.score:.3f}  {item.key}: {item.value}")
    finally:
        store.conn.close()


@memory_app.command("show")
def memory_show(namespace: str, key: str) -> None:
    """Show one memory item by exact key."""
    ns = tuple(namespace.split(","))
    settings = get_settings()
    store = open_memory_store(settings.memory_db, settings=settings, semantic=False)
    try:
        item = asyncio.run(store.aget(ns, key))
        if item is None:
            typer.echo(f"no item at {ns}/{key}", err=True)
            raise typer.Exit(code=1)
        typer.echo(item.value)
    finally:
        store.conn.close()


@app.command("persistence-test")
def persistence_test() -> None:
    """Run the cross-session persistence evidence script -> traces/memory_persistence.log."""
    script = _REPO_ROOT / "scripts" / "run_persistence_test.py"
    subprocess.run([sys.executable, str(script)], check=True)


if __name__ == "__main__":
    app()

import aiosqlite


@app.command()
def submit(sample_path: Path, session_id: str = typer.Option(None), member_id: str = typer.Option(None)) -> None:
    settings = get_settings()
    raw = json.loads(sample_path.read_text(encoding="utf-8"))
    submission = SampleSubmission(**raw)
    case_id = f"case-{uuid.uuid4().hex[:8]}"
    sid = session_id or f"sess-{uuid.uuid4().hex[:8]}"

    async def _run():
        conn = await aiosqlite.connect(settings.state_db)
        try:
            checkpointer = AsyncSqliteSaver(conn)
            with open_memory_store(settings.memory_db, settings=settings) as store:
                graph = await _build_graph_for_case(store, checkpointer)
                state = new_case_state(
                    case_id, sid, submission.member_id,
                    raw_provider_text=submission.raw_provider_text,
                )
                thread = {"configurable": {"thread_id": case_id}}
                tracer = RunTracer(
                    settings.traces_dir, case_id,
                    redact_values=default_redact_values(Path(settings.data_dir)),
                    session_id=sid,
                )
                result = await graph.ainvoke(state, config=thread)
                decision = result.get("decision")
                for step in result.get("route_history") or []:
                    tracer.event(step.to_node, "route", {"reason": step.reason})
                tracer.finish(decision=decision.model_dump() if decision else None)
                typer.echo(f"case_id={case_id}")
                if decision:
                    typer.echo(json.dumps(decision.model_dump(), indent=2))
                elif "__interrupt__" in result:
                    typer.echo(f"paused -- resume with: pac resume {case_id}")
        finally:
            await conn.close()

    asyncio.run(_run())

"""The single-agent baseline (design.md §10 PR7, NFR-06's comparison requirement):
one ReAct loop bound to every tool the four multi-agent workers collectively use, no
supervisor, no per-worker context selection, no quarantine boundary beyond what the
one system prompt states in words. Exists so `pac compare` has a REAL point of
comparison, not a strawman."""

from __future__ import annotations

from typing import Any

from langchain_core.tools import BaseTool

from pa_copilot.agents._react import get_agent_model, get_lite_agent_model
from pa_copilot.memory.tools import build_memory_tools
from pa_copilot.memory.store import PolicyStore
from pa_copilot.rag.tool import search_clinical_guidance
from pa_copilot.reflection import attribute_tool_errors, run_worker_react_resilient
from pa_copilot.schemas import PADecision

_SYSTEM_PROMPT = (
    "You are a single agent responsible for the ENTIRE prior-authorization "
    "adjudication task: extract the structured request from the raw provider "
    "submission, check plan benefits, assess medical necessity against payer "
    "criteria (using tools as needed), and produce a final PADecision. You have "
    "no supervisor and no specialized sub-agents -- do all of this yourself, "
    "calling tools directly."
)


async def run_single_agent(
    raw_provider_text: str,
    member_id: str,
    *,
    mcp_tools: list[BaseTool],
    store: PolicyStore,
    model=None,
) -> PADecision:
    manage, search_member = build_memory_tools(store, ("pa", "member", member_id))
    tools = attribute_tool_errors([*mcp_tools, search_clinical_guidance, manage, search_member])
    _messages, decision = await run_worker_react_resilient(
        model or get_agent_model(),
        tools,
        system_prompt=_SYSTEM_PROMPT,
        messages=[("user", raw_provider_text)],
        response_format=PADecision,
        lite_model=get_lite_agent_model(),
    )
    return decision

import streamlit as st  # noqa: E402


def _route_rows(route_history: list[Any]) -> list[dict]:
    """RouteStep list -> plain dicts for st.dataframe/st.table -- pure, no Streamlit call."""
    return [
        {"from": step.from_node, "to": step.to_node, "reason": step.reason}
        for step in route_history
    ]


def _artifact_rows(state: dict) -> dict:
    """The four structured artifacts, model_dump()'d where present, else None --
    what the center panel fills in as they arrive."""
    out = {}
    for key in ("request", "benefit", "necessity", "decision"):
        val = state.get(key)
        out[key] = val.model_dump() if val is not None else None
    return out


def _memory_panel_rows(working_memory: dict, long_term_hits: list[dict]) -> dict:
    """Right panel: working memory keys/values + any long-term store search hits used
    this run (caller supplies long_term_hits; this module doesn't call the store)."""
    return {"working_memory": dict(working_memory or {}), "long_term_hits": list(long_term_hits or [])}


def main() -> None:
    st.title("Prior-Authorization Copilot")
    left, center, right = st.columns([1, 2, 1])
    with left:
        sample_dir = _REPO_ROOT / "data" / "samples"

        pasted = st.text_area("...or paste a raw request", "")
        run_clicked = st.button("Run")
    with center:
        st.subheader("Routing trail")
        trail_placeholder = st.empty()
        st.subheader("Artifacts")
